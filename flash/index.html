Install on a ring (USB)

  1. Use Chrome or Edge on a computer.
  2. Ring switch OFF. Plug the ESP32 in with a USB-C data cable.
  3. Pick the controls PIN below. The ring Wi-Fi is open, so phones type this PIN before they can use the controls.
  4. Click Install and pick the port named USB JTAG/serial debug unit. Leave Erase device unticked to keep the ring's name, LED count and order.
Controls PIN
This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. USB access needs the secure (https) version of this page.

After the install finishes and you close the install window, this page sends the PIN to the ring.

A new ring measures its own strip the first time it runs on its battery. The newest PIN wins: when rings meet, they all switch to the most recently set one. If the board isn't listed: unplug it, hold BOOT, plug it back in, let go, and try again.

Update every ring at once (Wi-Fi)

  1. Download the update file: RingLink update file
  2. Switch the rings on and join the open Wi-Fi LED-Rings. The controls open; type the PIN.
  3. Open Rings → Firmware, pick the file, and tap Update all rings.

Each ring fills up green while it downloads, then restarts. The ring hosting the Wi-Fi goes last.

Control the rings

Over Bluetooth or USB (you stay on your normal Wi-Fi): connect to any ring and it hosts the controls for every ring that's on. Bluetooth works in Chrome or Edge (computer or Android) and in the free Bluefy browser on iPhone, and asks for the PIN. Over USB no PIN is needed. Over Bluetooth you can also update every ring's firmware (about a minute).

Control over Bluetooth / USB
